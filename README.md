## ✨ Features

- 🌐 **Interactive 3D Intelligence Core**: Real-time WebGL metallic sphere with orbital planetary rings, 180 particle starfields, and physics-based mouse tracking using Three.js & React Three Fiber.
- 🎨 **Sleek Cyber-Lab Aesthetics**: Dark graphite theme with emerald/lime accents, glowing glassmorphic panels, and fluid micro-interactions.
- 📊 **Academic & Skills Highlights**: Interactive 8.0 CGPA spotlight card, periodic-table style skill matrix, and animated strength badges.
- 🚀 **Projects Showcase**: AgriSentinel AI, Medicare AI, and Simple AI Chatbot with custom data-visualization SVGs and architecture breakdowns.
- 📜 **Verified Certifications**: Detailed credentials for Python Full Stack, Digital 101 App Fundamentals, and Generative AI.
- 📬 **Live Contact System**: Serverless API route with form validation and real-time response feedback.
- ⚡ **SEO & Performance**: 100% Lighthouse ready, semantic HTML5, OpenGraph metadata, and zero TypeScript compilation errors.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/dendukuripujitha04/pujitha-potfolio.git
cd pujitha-potfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
